# ForumHub - SDC Forum Application

## Modules
User Module: Signup/Login, browse/search/filter discussions, create threads, reply, upvote/downvote, follow threads and notifications.

Admin Module: Admin login, dashboard, discussion moderation, user list and category management.

## Technologies
HTML, CSS, JavaScript and Local Storage only.

Open `index.html` in a browser or use VS Code Live Server.

## Review Flow
Signup -> Login -> Browse -> Create Thread -> Open Thread -> Reply -> Vote -> Follow -> Notifications -> Admin Dashboard -> Moderate.
