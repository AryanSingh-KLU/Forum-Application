# ForumHub - SDC Forum Application

## Modules
User Module: Signup/Login, browse/search/filter published discussions, submit threads for review, reply, upvote/downvote, follow threads and notifications.

Admin Module: Admin login, dashboard, pending submission review (approve/reject), published discussion management, user list and category management.

## Technologies
HTML, CSS, JavaScript and Local Storage. The current pages are static frontend pages. Local Storage is a same-browser demo store and does not provide secure accounts or shared online data.

## Run
Install dependencies with `npm install`, then start the development server with `npm run dev`. Create a production build with `npm run build` and preview it with `npm run preview`.

## Review Flow
Signup -> Login -> Browse -> Submit Thread -> Admin Review -> Approve and Publish / Reject -> Reply -> Vote -> Follow -> Notifications -> Admin Dashboard.
